# <div align="center">RElog</div>
## How to install and use RElog
> DISCLAIMER: RElog Has Only Been Tested On Windows.
> 
> Some Features Might Not Work On MacOS/Linux.
### Installation(Python 3.X required)
First start by downloading RElog.py from /RequestTimeout/RElog/src/RElog.py and download the file.

Then, for easier access, place the `.py` file somewhere accessible like:
```text
C:\RElog\RElog.py
```
After that, if PyQt5 is not installed, you can open the terminal and run:
```bash
pip install PyQt5
```
Or you can download [requirements.txt](requirements.txt) and run(This needs you to open a terminal where the text file is located):
```bash
pip install -r requirements.txt
```
After the requirements are downloaded, you can open the terminal and run:
```bash
python "C:\RElog\RElog.py"
```
After that, everything is straight forward.
